# Contributing to mlx-power8

Thanks for taking the time to contribute!

## Setup

```bash
git clone https://github.com/Scottcjn/mlx-power8.git
cd mlx-power8
```

## Development Workflow

1. Fork the repository and clone your fork
2. Create a feature branch: `git checkout -b feat/my-feature`
3. Make your changes
4. Run tests (if available): `make test` or the project's test suite
5. Commit with a conventional commit message: `feat:`, `fix:`, `docs:`, `chore:`
6. Push and open a pull request against `main`

## Pull Request Guidelines

- Keep changes focused — one PR, one concern
- Write a clear PR title and descripion summarizing what changed and why
- Link any related issues in the description
- Ensure CI passes before requesting review

## Code Style

- Follow existing conventions in the codebase
- Keep diffs minimal — avoid reformatting unrelated code
- Write meaningful commit messages

## Reporting Issues

- Search existing issues before opening a new one
- Include steps to reproduce, expected behavior, and actual behavior
- Mention your enviroment (OS, version, etc.)

## Questions?

Open a discussion or issue — we're happy to help.
