# Contributing to MLX POWER8

Apple MLX ported to POWER8 Linux with VSX SIMD optimizations.

## Development Setup

```bash
git clone https://github.com/MingYu5/mlx-power8.git
cd mlx-power8
```

## Supported Systems

- IBM POWER8 (ppc64le)
- Linux with VSX SIMD support

## Contributing

1. Fork the repo
2. Create a feature branch
3. Test on real POWER8 hardware
4. Open PR against `Scottcjn/mlx-power8:main`

Questions? Open an issue!
